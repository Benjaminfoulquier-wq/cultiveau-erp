# Les gestes d'Odoo qui font gagner du temps

Pour les adhérents, à lire en cinq minutes (ou à montrer en deux minutes de vidéo). Rien à régler : tout est déjà dans
l'ERP. Le bouton « ? » en haut à droite affiche cette page quand l'écran n'a pas d'aide à lui.

1. **Ctrl + K** (Cmd + K sur Mac) : la palette de commandes. Tapez « devis », « Jean Martin », « map », « nouvelle intervention » :
   l'écran, la fiche ou l'action s'ouvre sans passer par les menus. Un « / » devant cherche dans les menus, un « @ » une personne,
   un « # » un canal de discussion.
2. **Alt** (Option sur Mac) : maintenu, il montre les raccourcis de l'écran (Alt + C créer, Alt + S enregistrer, Alt + J ignorer).
3. **La vue liste pour agir en masse** : cochez plusieurs lignes, puis changez un champ dans l'une d'elles : Odoo propose de
   l'appliquer à toutes (le type de contact de vingt clients, le technicien de dix interventions). Le menu Action : exporter,
   archiver, fusionner des contacts.
4. **Les colonnes au choix** : l'icône à droite de l'en-tête de liste ajoute ou retire des colonnes ; le réglage est gardé.
5. **Regrouper et filtrer** : le menu de recherche regroupe par n'importe quel champ et empile les filtres ; **Favoris › Enregistrer**
   garde la recherche, « par défaut » l'ouvre à chaque fois, « partagé » la donne à l'équipe.
6. **Dans les champs de date** : tapez `+7` pour dans sept jours, `+2m` pour deux mois ; dans une durée, `1:30` ou `1,5`.
7. **Le kanban** : glisser une carte change son étape ; en vue liste de la même action, on fait la même chose à plusieurs.
8. **Les activités** : l'horloge en haut regroupe tout ce qui vous attend ; depuis n'importe quelle fiche, « Planifier une activité »
   met un rappel daté (appel, visite, relance) ; marquer fait trace la chose dans le fil, et dans Effort commercial.
9. **Le fil de chaque fiche** : « Envoyer un message » écrit au client (e-mail), « Note » reste interne ; une pièce jointe se glisse
   dedans ; « @ » prévient un collègue.
10. **Les notifications dans l'ERP** plutôt que par e-mail : votre avatar › Préférences › « Gérer dans Odoo ».
11. **Le mode sombre** : votre avatar › Thème sombre.
12. **L'appli mobile** (Odoo sur Android et iOS, adresse erp.cultiveau.fr) : la même chose en poche ; les techniciens préfèrent
    « Ma journée » et le bon d'intervention.
13. **Mathis** (icône en haut à droite) : posez la question en français (« qui est en intervention ? », « il reste combien de PE 63 ? »,
    « montre-moi les devis par commercial ce trimestre ») ; il agit après votre accord.
14. **La map vivante** : **/** cherche tout, **T** lance la visite, **H** la vue d'ensemble, **Échap** ferme ; clic droit tourne, molette zoome.

À montrer aux nouveaux la première semaine, dans cet ordre : Ctrl + K, la liste en masse, les activités, Mathis.
